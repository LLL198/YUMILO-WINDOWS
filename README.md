# Yumilo Windows

Yumilo Windows 播放器更新仓库。本仓库仅提供发布说明与成品更新包，不托管播放器项目源码。

## 下载

请到 [Releases](https://github.com/LLL198/YUMILO-WINDOWS/releases/latest) 下载最新 Windows x64 便携包。

完整解压后运行根目录的 `Yumilo.exe`，并保留同目录的 `app` 文件夹。用户配置独立保存在 `%LOCALAPPDATA%/Yumilo/Windows/`，更新程序不会清除已有账号与设置。

## 程序内更新

在设置的“数据”页选择“Windows 更新”，手动检查最新正式版本，确认后下载并安装。更新包使用 GitHub 提供的 SHA-256 摘要校验；Release 同时提供独立校验文件。

旧版程序如果尚未接入此仓库，请先手动下载并解压新版。未来更新可继续使用程序内检查更新。
